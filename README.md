# นารายณ์ราชา: มหาราชแห่งอยุธยา

**Turn-based Strategy RPG ผสม Visual Novel** — เล่นเป็นสมเด็จพระนารายณ์มหาราช บริหารราชอาณาจักรอยุธยาให้เจริญรุ่งเรือง

## เกี่ยวกับเกม

ย้อนไปยุค พ.ศ. 2199–2231 คุณคือกษัตริย์แห่งกรุงศรีอยุธยา ตัดสินใจเรื่องการค้า การทูต และการทหาร ท่ามกลางการแข่งขันของมหาอำนาจจากทั่วโลก

## วิธีเล่น

เปิดไฟล์ `index.html` ในเว็บเบราว์เซอร์ได้เลย — **ไม่ต้องติดตั้งอะไรเพิ่ม**

```
# หรือใช้ Live Server
npx serve .
```

## ระบบในเกม

| ระบบ | รายละเอียด |
|------|-----------|
| **การค้า** | ส่งสินค้าค้าขายกับ 5 ชาติ (ฮอลันดา, ฝรั่งเศส, จีน, ญี่ปุ่น, เปอร์เซีย) |
| **การทูต** | ส่งราชทูต ลงนามสนธิสัญญา สร้างพันธมิตร |
| **การทหาร** | จัดกองทัพ 5 หน่วย ออกรบ 3 สมรภูมิ |
| **เหตุการณ์** | Visual Novel 16 เหตุการณ์ใน 5 บท ตัดสินใจที่เปลี่ยนทิศทางเกม |
| **ที่ปรึกษา** | วิชาเยนทร์, พระเพทราชา, โกษาปาน — แต่ละคนมีวิสัยทัศน์ต่างกัน |
| **Save/Load** | บันทึกเกมอัตโนมัติผ่าน LocalStorage |

## ทรัพยากร

- **ทองคลัง** — ใช้ในการค้า สร้าง จ้างทหาร
- **อาหาร** — เสบียงสำหรับประชาชนและกองทัพ
- **ศรัทธา** — ความศรัทธาของราษฎร
- **อำนาจ** — ความเข้มแข็งของราชบัลลังก์
- **ชื่อเสียง** — ชื่อเสียงในเวทีนานาชาติ

## 4 ตอนจบ

| ตอนจบ | เงื่อนไข |
|-------|----------|
| ยุคทองแห่งอยุธยา | สมดุลอำนาจ ชื่อเสียง และความมั่งคั่ง |
| จักรวรรดิการค้า | สร้างเครือข่ายการค้ามหาศาล มีสนธิสัญญามากมาย |
| ภายใต้เงาต่างชาติ | อำนาจตกอยู่ในมือชาวต่างชาติ |
| สงครามกลางเมือง | พระเพทราชาก่อกบฏยึดอำนาจ |

## โครงสร้างโปรเจกต์

```
Naraigame/
├── index.html          # HTML หลัก
├── css/
│   └── style.css       # ธีมทอง-แดงชาดอยุธยา
├── js/
│   ├── game-state.js   # สถานะเกม, Turn System, Save/Load
│   ├── characters.js   # ตัวละครและที่ปรึกษา
│   ├── events.js       # เหตุการณ์ Visual Novel (16 เหตุการณ์)
│   ├── trade.js        # ระบบการค้า
│   ├── diplomacy.js    # ระบบการทูต
│   ├── military.js     # ระบบการทหารและการรบ
│   ├── map.js          # แผนที่อาณาจักร
│   ├── ui.js           # จัดการ UI
│   └── main.js         # Game Loop หลัก
└── NARAI_GAME_PROMPT.md # เอกสารออกแบบเกม
```

## เทคโนโลยี

- HTML5 + CSS3 + Vanilla JavaScript
- ไม่มี dependency ใดๆ — เปิดเบราว์เซอร์เล่นได้เลย
- ฟอนต์: Kanit + Sarabun (Google Fonts)

## ข้อมูลทางประวัติศาสตร์

เกมนี้ได้รับแรงบันดาลใจจากประวัติศาสตร์จริงในรัชสมัยสมเด็จพระนารายณ์มหาราช (พ.ศ. 2199–2231) แต่มีการปรับแต่งเพื่อความสนุกของ gameplay บุคคลและเหตุการณ์หลักอ้างอิงจากหลักฐานทางประวัติศาสตร์
